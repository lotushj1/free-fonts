## 使用須知

1. **授權確認**：使用前請到各字體官方網站確認授權範圍（個人／商用、能不能改作或做 Logo）。
2. **缺字問題**：日文或簡中字體可能缺少部分繁體中文字，台灣做的字體也不一定字多，先用實際文案打一遍。
3. **版本更新**：字體可能更新版本，建議到官方網站下載最新版。
